# Keyboard Shortcuts

Speed up your workflow with these keyboard shortcuts in the session player.

## Navigation

| Key            | Action              |
| -------------- | ------------------- |
| `Space`        | Play/Pause          |
| `←` / `→`      | Previous/Next frame |
| `Home` / `End` | First/Last frame    |

## Panels

| Key      | Action                 |
| -------- | ---------------------- |
| `a`      | Toggle Artifacts panel |
| `f`      | Toggle Filters popup   |
| `Escape` | Close panel/popup      |

## Playback

| Key   | Action                     |
| ----- | -------------------------- |
| `1-9` | Set playback speed (1x-9x) |

## Search

| Key                | Action      |
| ------------------ | ----------- |
| `Cmd+K` / `Ctrl+K` | Open search |
